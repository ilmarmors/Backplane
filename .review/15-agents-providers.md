## Summary
The unit turns seven agent CLIs (Codex, Grok, OpenCode, Muse, Antigravity in two forms, Pi, Oh My Pi) into one set of "Codex shapes": each driver is a small pure state machine for one process per turn, and the actor in `agents/mod.rs` owns the process, the events and the approval cards. The translation code is careful and well covered by unit tests and by stand-in runs compared with logs recorded from the old JS hub. The risks are at the seams, where no test looks. A ledger rule written for Claude ends a driver's turn after 120 s of silence once a thread has been switched from Claude, which is exactly what the failover does. No driver has a time limit, so a CLI that never answers leaves a turn running for ever. Secrets cross two seams the wrong way: the thread's MCP key is in Codex's argv, and the stdin mask replaces the header secrets the ACP agents are meant to receive. Supervision is uneven: "Auto" is full access on three providers, "Allow for session" is keyed on a coarse tool kind and never expires, Pi and Oh My Pi run Backplane's own command tools unasked, and two mode changes are not checked. Session handling differs per provider (four cannot recover a lost session, one cannot start a fresh one, one loses it silently). About a third of the unit (the pinned Antigravity agent's install and sign-in, a second private copy of the ACP translator, listing scripts) is not reached by the Rust hub, while messages still send the person to a Settings page that does not exist.
