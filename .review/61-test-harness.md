## Summary
The harness is carefully built where it was written recently: the guard and update drivers (faults.sh, feed.sh, install-e2e.sh, nightly-update.sh, rc-smoke.sh) use a private HOME, a private home and port, `--no-tailscale`, `BACKPLANE_AGENTS`, a fresh test key, `trap ... EXIT` clean-up, and assert on the hub's own state (status.json, BAD, /hello identity) rather than on exit codes. `own-group.sh` is a correct answer to the no-kill-by-name rule, and no script in my unit uses pkill, killall or `pgrep -f`. The weaknesses are of three kinds. First, the Boat wrappers and several scale scripts in test/hub are dead: they name scripts and flags that no longer exist. Second, a few drivers pass vacuously (an unknown case name runs nothing and exits 0; a skipped case counts as PASS; win-r.ps1 and desktop_flow.sh only print). Third, there are small rule slips (`/tmp` scratch, hubs started without `--no-tailscale`, fixed ports that a foreign listener can satisfy) and timing-based negative assertions. The stand-in agents are good protocol fixtures for the happy path and for process-lifecycle quirks, but they cannot produce most real failure classes (see Improvements), which bounds what agent tests can prove. Signature failures are covered for wrong key, key ceiling, identity mismatch, older version; tampered archive and tampered manifest are not.

## Style nitpicks
- Dense one-line functions in capture.mjs, frames.mjs, hubrows.mjs, and compound `a && b && ok || no` chains in rc-smoke.sh (`||` also fires if `ok` fails).
- `win-r.mjs` and `send-turn.mjs` end with `process.exit(0)` regardless of the reply's `ok`; callers cannot tell a refused call from a done one.
- faults.sh `stopall` sends `kill -9` after a 15 s wait and leaves a hub orphaned if only the guard dies; use the own-group helper.
- The comment at test/e2e/lib/own-group.sh:3 reads as if the problem were fixed in `own()` only; `own_stop` also depends on `setsid` existing (absent on macOS).
- make-home.py reads the hub source tree to learn event names, so a renamed variant silently drops out of the fixture; the fallback list is used only when none are found.
