## Summary
This unit is the presenter's small pure modules: sidebar sections and project pages, file and app-link planning, the token/cost panel, the new-bot, room, routine and swarm forms, project badges, the Buy-it card, POSIX time zones, and the signed paging cursors of the native sidebar. Most of it is pure, deterministic and well tested; the MAC cursor code, the time-zone arithmetic and the token formatting held up under tracing. The main risk is `filelink.rs`: a message link to any existing file that is not a design file or previewable type becomes `Plan::Os`, and the hub then runs the system opener (`open` on macOS) on it with no type filter, so a link to a `.command` or `.app` file starts it. Second, Windows paths are mangled by `absolute`. Third, the project page silently drops threads past 660 Done rows and past 60 Recent rows although its comment promises "none hidden", and the context tip underflows when `used > window`. The forms trust client text with no length or character limits, but the hub re-validates the important fields.

## Missing tests
- `plan`/`absolute`: a link to an existing `.command`, `.app`, `.sh` path must not become a plain `Os` (once fixed); a Windows `C:\...` link; `file://host/path` with a non-local host; `%2e%2e` and `%00` after decoding; `mailto:x` and `javascript:` hrefs.
- `page()`: more than 660 Done threads, and more than 60 Recent threads (count and reachability).
- `usage()`: `used > window` (tip and hint), `window == 0` with a `[1m]` tag, and `runway` with equal readings.
- `tz`: `J` and `N` day rules (leap year, day 60), week 5 in a 4-week month, negative DST (Europe/Dublin `IST-1GMT0,M10.5.0,M3.5.0/1`), negative transition times (`M3.5.0/-1`), and an instant at 23:59 on Dec 31 near a transition.
- `linkopen::plan`: the `bpgpui://` and `backplane-gpui://` aliases, a url over 4096 bytes, `conv` ids of the three forms.
- `swarmform`: a model value with a tab or newline; `botforms`: a `room-pick` id with a newline, and `bfield` with very long text.
- `sections::act`: `group-move` to an unknown group id, `group-new` with a punctuation-only name, `thread-hide` on a local thread.
- `jump`: a hidden far thread stays listed (the `State::new()` call for `facts` relies on it).
