## Summary
The unit parses KiCad boards and schematics (a byte-level S-expression reader, board and schematic item builders, a Hershey stroke-font layout), turns items into delta-coded plot chunks for the viewers and phones, compares versions and walks schematic sheet trees, and reads Gerber (RS-274X/X2) and Excellon fab output to draw it and compare it with its board on a raster grid. The code is compact and mostly careful: the S-expression reader is iterative with a depth cap, slicing is guarded, numbers are parsed without panics, malformed Gerber and drill lines are reported per line and the rest is kept. Since `BACKPLANE_PLOT_NATIVE` defaults on, all of this runs inside the hub process (watch.rs `run_native`), where `catch_unwind` protects only against panics: allocation failure and stack overflow still abort the hub. Several Gerber constructs let a small file request unbounded work or memory (polygon and outline vertex counts, step-and-repeat counts, macro expression nesting), and a schematic's sheet path can point the reader at `/dev/zero`. On correctness, the 2D board reader turns pads the wrong way (custom pads at 90 degrees, rectangular pads at 45 degrees), which also produces false differences in the Gerber comparison. The comparison itself has blind spots: features narrower than about 0.125 mm can never register, the grid stops at 200 mm, inner layers past In6 are neither drawn as copper nor compared, and a set plotted with the aux origin reports everything as different. Repeated hierarchical sheets show the property reference, not the per-instance reference. Tests cover the happy paths and a few malformed lines, but none feeds hostile sizes, deep nesting or device paths.
