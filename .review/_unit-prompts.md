# Per-unit files and focus

Each reviewer reads only the section of its own unit (the heading `## NN name`). The rules, checklist and output layout are in `_reviewer-brief.md`; the shared context is in `00-map.md`. `H/` means `native/host/src/`, `G/` means `native/gpui/src/`, `A/` means `mobile/android/app/src/main/java/dev/backplane/mobile/`, `I/` means `mobile/ios/Backplane/`. Test files inside a unit are read to judge coverage, not line by line.

## 13 agents-turn-support
Files (256 KB): H/agents/lines.rs, inputs.rs, halt.rs, halt_view.rs, hist.rs, host.rs, wake.rs, work.rs, tasks.rs, bg.rs, settle.rs, cmds.rs, codex.rs, devturns.rs, far.rs, recall.rs, review.rs, laws.rs. Docs: docs/wakes.md, docs/work-recovery.md, docs/COPY-GUARD.md.
Focus: `lines.rs` parses the agent CLIs' output stream (malformed, partial, very long or non-UTF-8 lines; unknown message types). `inputs.rs`: what is written to an agent's stdin. `halt.rs`, `halt_view.rs`: stopping turns, races with a result. `hist.rs`: what it writes and where (COPY-GUARD.md says it wrote on a copy hub). `wake.rs`: timers, lost or duplicate wakes after a restart, clock jumps. `work.rs` (`work_run`): commands agents run through the hub (time limits, output caps, process groups, memory scopes, what a copy hub refuses). `tasks.rs`, `bg.rs`: background tasks and shells (results delivered once, leaks, orphans at hub exit). `far.rs`: agent tools that reach other machines. `codex.rs`, `cmds.rs`, `laws.rs`, `settle.rs`.
