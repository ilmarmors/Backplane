# 95 Missing features

Commit `9c6c5448a514ebcddca5a776933793e25179a796`. Baseline: the "Stated intent" list in `00-map.md` (README, AGENTS.md, docs). Inputs: the 483 feature-gap rows the unit reviewers recorded (each unit file has its own "Feature gaps" table with the full rows), checked and merged here. Rows marked "lead" were re-checked by the lead reviewer against the code.

Categories:

- **Promised**: documented or advertised, but absent or not working.
- **Partial**: started in code but incomplete (stubs, ignored options, one platform or one provider only).
- **Inferred**: not promised, but a user of this kind of product would reasonably expect it. Each has a one-sentence reason tied to how the product is used.

Effort: S is hours to a day, M is days, L is weeks. Paths are relative to the repository root; `H/` means `native/host/src/`, `G/` means `native/gpui/src/`, `A/` means `mobile/android/app/src/main/java/dev/backplane/mobile/`, `I/` means `mobile/ios/Backplane/`.
